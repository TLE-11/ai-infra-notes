# 实验

用小实验检查自己是否真正理解规则。先写出预测，再看参考答案；记录哪些假设会改变结论。

| 实验 | 环境 | 会验证什么 |
|---|---|---|
| [你来分配 100 张 GPU](01-share-100-gpus.md) | Python 3.9+ 或纸笔，无需 GPU | 借用、回收、抢占、硬上限和任务粒度 |

在仓库根目录运行：

```bash
python3 labs/simulate_100_gpus.py
```

脚本只用 Python 标准库，逐步打印资源变化。可以先做纸面题，再运行对照答案；模拟不会访问 GPU 或真实集群。
